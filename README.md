# 2D Car with Python Turtle

A detailed 2D car illustration created with Python's built-in `turtle` module.
The drawing uses polygons, ellipses, circles, layered colors, and shadows to
create a car with a pseudo-3D appearance.

## Preview

When the program runs, it opens a Turtle graphics window containing:

- A detailed red car body
- Windows with highlights and reflections
- Wheels with rims and spokes
- Headlights, taillights, grille, bumper, mirrors, and antenna
- Road markings, sky, clouds, and a ground shadow

## Requirements

- Python 3.9 or newer
- No external packages are required
- Tkinter, which is included with standard Python installations

## How to run

Clone the repository:

```bash
git clone https://github.com/mnurkholiss21/2dcar-py-turtle.git
cd 2dcar-py-turtle
```

Run the program:

```bash
python mobil.py
```

On Windows, you can also run:

```powershell
py mobil.py
```

Close the Turtle window to exit the program.

## What this project demonstrates

- Drawing reusable shapes with Python functions
- Working with Cartesian coordinates
- Using polygons and curves to build an illustration
- Creating depth with offset shapes and color layers
- Organizing a Turtle graphics project into small drawing functions
